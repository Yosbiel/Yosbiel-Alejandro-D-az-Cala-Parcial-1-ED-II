# Sistema de Gestión de Viviendas – Guane

## Descripción
Sistema desarrollado en Java para gestionar viviendas en el municipio Guane, Pinar del Río. Utiliza un **árbol general (N-ario)** implementado desde cero para representar la jerarquía geográfica:  
**País → Provincia → Municipio → Consejos Populares → Viviendas**

## Funcionalidades
- Inserción de viviendas en Consejos Populares
- Búsqueda de viviendas por propietario
- Listado de viviendas por Consejo Popular
- Recorridos BFS (por niveles) y DFS (en profundidad)
- Métricas del árbol: altura, cantidad de nodos, grado

## Tecnologías utilizadas
- Java (JDK 8+)
- NetBeans
- Estructura de datos personalizada (árbol general)
